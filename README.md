# Cybersecurity Lab

A personal cybersecurity learning lab focused on understanding, testing, and securing web applications and APIs.

## Goals

- Understand web and API security fundamentals
- Learn authentication and authorization security
- Practice common web vulnerabilities in a controlled local environment
- Analyze vulnerabilities and their root causes
- Implement and test security fixes
- Learn responsible vulnerability disclosure
- Build practical skills for bug hunting

## Tech Stack

- Go
- Gin
- PostgreSQL
- Docker
- Burp Suite
- curl
- Git

## Learning Topics

- Authentication & JWT
- Authorization & IDOR
- SQL Injection
- Cross-Site Scripting (XSS)
- Path Traversal
- File Upload Security
- SSRF
- Business Logic Vulnerabilities
- API Security
- Reconnaissance
- Vulnerability Research
- Responsible Disclosure

## Disclaimer

This repository is intended for cybersecurity education and authorized security testing only.

All vulnerability testing should be performed against systems owned by the user, intentionally vulnerable training environments, or targets where explicit authorization has been granted.
